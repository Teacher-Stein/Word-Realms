How To Play

  • The teacher picks one student at a time. That student makes ONE choice: which path to take on the map, or which answer to pick in a challenge.
  • Every Fight and Elite node is a review question from the unit. Answer right to win the encounter; answer wrong and the party loses a heart.
  • Event nodes are a story choice — no combat, sometimes a small reward either way.
  • Rest nodes heal a heart. Treasure nodes ask a bonus question for a relic or hint token.
  • Some paths dodge fights entirely (Safe Path) but skip the reward too.
  • Reach the Realm Boss to finish. The boss always tests everything in the unit, so nothing gets skipped for good.
  • Run out of hearts and the run resets with a new map — but the party keeps a relic or banked Ember (meta-currency) to help next time.
